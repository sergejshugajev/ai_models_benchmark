# AI Models Benchmark v2

## Назначение

Простой автономный стенд для отдельного тестирования `qwen3-coder` или `devstral` через локальный API Ollama.

## Работа программы

1. Показывает две заданные в коде модели и предлагает выбрать одну по номеру.
2. Отправляет выбранной модели встроенный тест на написание Python-функции.
3. Показывает потоковый ответ и метрики в консоли.
4. Сохраняет отдельный текстовый отчёт с моделью и временем в имени.

## Требования и запуск

- Python 3, только стандартная библиотека.
- Запущенная Ollama на `http://localhost:11434`.
- Установленные модели `qwen3-coder` и `devstral`.

Запуск:

```text
python ai_models_benchmark.py
```

## Ограничения

- Список моделей и тест встроены в программу.
- За один запуск тестируется только одна модель.
- Переключение и выгрузка тяжёлых моделей не контролируются.
- Отчёт создаётся в текущей рабочей директории.
