# AI Models Benchmark v8

## Назначение

Простой автономный стенд для отдельного тестирования любой установленной модели Ollama.

## Работа программы

1. Получает через Ollama API список реально установленных моделей.
2. Показывает найденные модели и предлагает выбрать одну по номеру.
3. Проверяет через `ollama ps`, какие модели находятся в памяти.
4. Останавливает другие модели без дополнительного цикла ожидания.
5. Находит рядом со скриптом тестовые `.md` и предлагает выбрать один по номеру.
6. Отправляет модели содержимое выбранного теста без первой строки-заголовка.
7. Показывает потоковый ответ и метрики в консоли.
8. Сохраняет рядом со скриптом отдельный отчёт с моделью, тестом и временем в имени.
9. При ошибке показывает её, сохраняет в отчёт и оставляет окно открытым.

## Требования и запуск

- Python 3, только стандартная библиотека.
- Запущенная Ollama на `http://localhost:11434`.
- Хотя бы одна установленная модель Ollama.
- Хотя бы один `.md` рядом со скриптом: первая строка `# Название`, далее промт.

Запуск:

```text
python ai_models_benchmark.py
```

## Ограничения

- Файлы без Markdown-заголовка в первой строке игнорируются.
- За один запуск тестируется только одна модель.
- После `ollama stop` программа полагается на штатное поведение Ollama.
- Ollama должна отвечать в момент запуска.
- Завершение программы требует нажатия Enter.
