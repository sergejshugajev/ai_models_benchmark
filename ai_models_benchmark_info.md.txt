# AI Models Benchmark v1

## Назначение

Первая версия — простой автономный стенд для сравнения `qwen3-coder` и `devstral` через локальный API Ollama.

## Работа программы

1. Последовательно запускает две заданные в коде модели.
2. Отправляет каждой одинаковый встроенный тест на написание Python-функции.
3. Показывает потоковый ответ в консоли.
4. Выводит краткое сравнение скорости.
5. Сохраняет один общий текстовый отчёт в текущей рабочей директории.

## Требования и запуск

- Python 3, только стандартная библиотека.
- Запущенная Ollama на `http://localhost:11434`.
- Установленные модели `qwen3-coder` и `devstral`.

Запуск:

```text
python ai_models_benchmark.py
```

## Ограничения

- Список моделей и тест встроены в программу.
- За один запуск обязательно тестируются обе модели.
- Переключение и выгрузка тяжёлых моделей не контролируются.
- Отчёт имеет постоянное имя и перезаписывается следующим запуском.
